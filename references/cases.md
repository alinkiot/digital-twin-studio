## 4. 武汉长江大桥数字沙盘（`bridge` / 公铁两用桁架桥）

| 项 | 值 |
| --- | --- |
| bbox | `114.268,30.532 – 114.306,30.560`，`W=910.8`、`H=773.8` |
| 栅格 | Copernicus DEM 7.6–97.2 m + WorldCover；江面 `DEM<18 m`，与 WorldCover 80 双源互证 |
| 江面几何 | 逐行最长连续低地拟合江中心线 `lon = 114.280370 + 0.454771×(lat−30.545)`；桥轴线取法向 `(0.9303, −0.3669)`；沿轴线采样实测跨江 1,150 m（公开 1,126 m） |
| 矢量 | 本轮 Overpass 6 镜像全不可达（504/406/超时/502）→ 示意路网 19.3 km + 871 栋建筑 + 8 处地标，`osm_ok=false` |
| 设计参数 | 全桥 1,670.4 m；正桥 1,155.5 m（3 联 9 孔 ×128 m）；汉阳引桥 303.45 m / 武昌引桥 211.45 m；8 水中墩；2 桥头堡 35 m；桁高 16 m |
| 双层 | 上层公路 22.5 m（双向四车道）/ 下层铁路双线 14.5 m；平弦米字形钢桁梁，每孔 8 个 16 m 大节间 |
| 渲染 | `ZEX=3.2`、地形 `×0.60`、`WVIS=4.0`、`BEX=0.54`；主视 `dist=980, ph=0.37`；右上角画中画独立相机 `fov=32, dist=360, ph=0.15` |
| 表达性渲染 | 江面顶点色（江心深 / 近岸浅）+ 自定义水面 shader（域扭曲波纹 / 菲涅尔 / 按主光方位投影的桥影 / 日轮高光 / 距离雾）；地形山体提绿 / 建成区压暗、周边建筑按离桥距离衰减亮度与高度、桥头堡 7 层窗带 + 金色挑檐 + 宝顶 |
| 质感层 | `MeshStandardMaterial` + 1024 软阴影 + 半球天光、天空穹顶（渐变 / 远山剪影 / 日轮）、三档光影氛围（科技蓝 / 写实黄昏 / 夜景灯光）、日照方位滑块、夜景 `Points` 灯带、UI 入场动效与大气辉光；配方见 `visual_fx.md`、片段库 `scripts/visual_fx.py` |
| 交互 | 5 机位（含双层分解）/ 11 图层 / 22 可点选构件 / 剖切 / 搜索 / 网格底座 / **桥身细部双视口画中画** / 三档氛围与日照方位 |
| 产物 | `out/武汉长江大桥_数字沙盘.html`（单文件离线）、`武汉长江大桥_沙盘图.png` + `_沙盘图_黄昏.png`（无 UI + 信息展板）、`武汉长江大桥_{主预览,wide,floors,cut,skel,top,pick}.png`、三套氛围对比图 `武汉长江大桥_主预览_{写实黄昏,夜景灯光}.png`、`武汉长江大桥_说明.md`、`武汉长江大桥_冒烟报告.json`、`武汉长江大桥_raster/` |
| 脚本 | `wuhan_bridge/build_wuhan.py` / `wuhan_bridge/make_wuhan_html.py` / `wuhan_bridge/make_clean_plate.py`（技能内 `assets/templates/sandbox/`，含 `README.md` 改常量清单；质感层已抽为 `scripts/visual_fx.py`） |
| 验收 | 7 视角截图全绿无 `Uncaught`，`smoke_check.py` 11/11 |

关键处理：
- **江面判定要与江道走向一起求**：先逐行找最长连续低地段拟合中心线，再取法向做桥轴线，
  沿轴线采样确定跨江段，比手工猜桥位可靠得多。
- **垂江道路必须按水面断段**：只 `skip` 水格点会让 `buildRibbon` 把两岸点直接连成跨江假斜线
  （本版踩过，已修）；沿江大道同理。
- `bar()` 用三向十字截面（水平两正交 + 垂直）画桁架杆，任意视角都可见，比单面 quad 稳健。
- 双层分解要在 `setMode` 里**所有 `setLayer` 复位之后**再 `applySep`，否则图层复位会把桁架重新打开。
- 纯净沙盘图：注入 CSS 隐藏所有 UI **与 3D 浮动标签**（`.lab{display:none!important}`）、关掉画中画（`setInset(false)`），叠一张信息展板，用更大窗口截图，可直接当图交付。
- **沙盘全景里主角太细**时，不要一味放大 `WVIS`：用一个独立相机的右上角画中画（`setViewport` + `setScissor` 双视口）同时给「整体沙盘」和「构件特写」，比把整个场景拉近更可控。
- 画中画只在全景 / 俯视显示；骨架与双层模式用 `setInset(false)` 收起；点选属性面板时 CSS `#right.show~#inset{display:none!important}` + loop 里 `blocked` 同步停掉 3D 双视口，否则边框会压在属性面板上。
- 江面别加等间距 `LineSegments` 流线：规则短线阵列在斜向水面上形成摩尔纹 / 雨丝感，只用顶点色深浅渐变反而干净。
- 纯净图机位用四角投影 NDC 反算（底座 8 角 `project(camera)` 全落 `[-1,1]`），不要凭肉眼猜 `dist` / `ph`。
- **质感增强一轮**（`MeshStandardMaterial` + 1024 软阴影 + 天空穹顶 ShaderMaterial + 水面 ShaderMaterial + 三档光影氛围 + 夜景 `Points` 灯带）：最见效的是软阴影与天空/水面，而不是继续堆几何；新增 UI 行要同步放宽左侧面板 `max-height`，否则构件清单被挤到滚动区外。本轮已抽成 `scripts/visual_fx.py`（`TwinFX.install`）+ `references/visual_fx.md`，新项目可直接内联复用。
- 水面 shader 先做**域扭曲**再采样正弦，等间距波纹在斜向江面上必然变摩尔纹；镜面高光指数降到 `pow(sh,26~110)` 在俯视机位才可见，幅度过大又会变成满江碎白斑，需要反复目检收敛。
- **桥影**可按主光方位把桥面高度投影到水面（`off = -L.xz * h / L.y`，沿桥轴与法向做带状遮罩），配合「日照方位」滑块能看到影子随太阳移动，是低成本高收益的真实感细节。

## 四者对比

| 维度 | 西湖 | 江东大桥 | 黄鹤楼 | 武汉长江大桥 |
| --- | --- | --- | --- | --- |
| 主角 | 面状城区 / 水系 | 悬索桥构件 | 点状单栋楼阁 | 公铁两用桁架桥 |
| 矢量 | 真实 OSM | 真实 OSM | 示意（OSM 不可达） | 示意（OSM 不可达） |
| 江/湖面 | H5 waterGrid | DEM `<3 m` | DEM `<20 m` | DEM `<18 m` + WorldCover 互证 |
| 精度 | LOD1 体块 | 构件级示意 | LOD2 逐层可点选 | 构件级 + 双层分解 |
| 剖切方式 | clipping plane | 高度剖切 | 楼层剖切 + 爆炸展开 | 高度剖切 + 双层分离 |
| 画质 | 科技蓝矢量 | 科技蓝矢量 | 科技蓝矢量 | 科技蓝 + 写实黄昏 + 夜景灯光 |
| 回答的问题 | 城区长什么样 | 桥由哪些构件组成 | 每层楼都能看清 | 公铁两用结构如何叠合 |

「每层楼都能看清」在无 IFC 时只能靠**逐层独立构件**；
要楼层可量测仍需竣工 BIM / IFC（IfcBuildingStorey / IfcSpace）、
CAD 翻模或 Scan-to-BIM，再导出 glTF / 3D Tiles 挂 Cesium。
